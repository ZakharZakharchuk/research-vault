# Налаштування: від нуля до першої зібраної статті

Час: **~1–1,5 год**, з них половина — встановлення програм. Кроки по порядку; кожен закінчується перевіркою «✓ готово, якщо…».

Назви пунктів меню наведено для Windows і версій жовтня 2026 — у вас можуть трохи відрізнятись.

## Що знадобиться

| Програма | Навіщо | Де взяти |
|---|---|---|
| Claude (desktop app) з Cowork | асистент, що веде конвеєр | claude.ai/download; потрібна платна підписка |
| Zotero 7 + конектор для браузера | бібліотека статей і PDF | zotero.org |
| Better BibTeX для Zotero | стабільні citekey і автоекспорт `.bib` | github.com/retorquere/zotero-better-bibtex → Releases → `.xpi` |
| Obsidian | нотатки й панель черг | obsidian.md |
| Git (+ акаунт GitHub, бажано) | версії й резервна копія | git-scm.com |
| Python 3 | скрипти обліку | python.org (під час встановлення — галочка «Add to PATH») |

## 1. Отримати шаблон (5 хв)

**Варіант А — GitHub (рекомендовано):**

1. На сторінці шаблону: **Use this template → Create a new repository**. Назва — напр. `research`, видимість — **Private**.
2. Клонувати в папку, де житиме робота (шлях без кирилиці й пробілів — менше сюрпризів):
   ```
   git clone https://github.com/<ви>/research.git D:\study\research
   ```

**Варіант Б — архів:** розпакувати `research-vault.zip` у `D:\study\research`. Git ініціалізує `vault-setup` на кроці 6.

✓ готово, якщо в `D:\study\research` є `CLAUDE.md`, `SETUP.md` і папки `00_admin` … `90_pipeline`.

## 2. Python (5 хв)

```
cd D:\study\research
pip install pyyaml
python 90_pipeline/collect/state.py .
```

✓ готово, якщо скрипт надрукував блоки «Бібліотека», «Нотатки за статусами» без помилки (повідомлення «library.bib ще немає» — нормально, це наступний крок).

Необов'язково: `pdftotext` (пакет poppler) пришвидшує читання PDF. Без нього Claude читатиме PDF у хмарі — працює, але довше.

## 3. Zotero + Better BibTeX (15 хв)

1. Встановити Zotero 7 і конектор для браузера.
2. **Інструменти → Плагіни → ⚙ → Install Plugin From File…** → вибрати завантажений `.xpi` Better BibTeX → перезапустити Zotero.
3. **Правка → Налаштування → Better BibTeX → Citation keys**, поле *Citation key formula*:
   ```
   auth.lower.len + year; shorttitle(2,0).lower + year
   ```
   Друга частина — для джерел без автора, інакше ключем стає голий рік.
4. **Автоекспорт:** клік правою на «Моя бібліотека» → **Експортувати бібліотеку…** → формат **Better BibTeX**, галочка **Keep updated** → зберегти як `D:\study\research\00_admin\library.bib`.
5. Запам'ятати, де Zotero тримає PDF: **Налаштування → Додатково → Файли й теки → Каталог даних**. Потрібна тека `storage` всередині, зазвичай `C:\Users\<ім'я>\Zotero\storage`.

✓ готово, якщо `00_admin\library.bib` з'явився, а після додавання будь-якої статті в Zotero він оновлюється сам за кілька секунд.

## 4. Obsidian (5 хв)

3. Zotero Integration при першому імпорті може попросити завантажити PDF-утиліту — погодитись.

✓ готово, якщо `10_literature/_matrix.md` показує таблиці (поки порожні), а не сирий код ```` ```dataview ````.

## 5. Claude (15 хв)

1. **Скіли.** Файли — у `skills/dist/` сховища.
   - **Cowork (desktop app):** перетягнути `research-vault.plugin` у чат Cowork і підтвердити встановлення в картці плагіна. Ставить усі 5 скілів разом.
   - **Або claude.ai:** **Settings → Capabilities → Skills → Upload skill** — по черзі 5 файлів `.zip`.
2. **Конектор Consensus** (пошук наукових статей): **Settings → Connectors** → знайти **Consensus** → Connect. Без нього Stage 1 працюватиме лише через arXiv.
3. **Проєкт.** Створити Project, напр. «Дипломна». Інструкції поки не вставляти — їх заповнить крок 6.
4. **Нова задача в Cowork** всередині проєкту → підключити **дві папки**: сховище (`D:\study\research`) і сховище PDF Zotero (`C:\Users\<ім'я>\Zotero\storage`).

✓ готово, якщо в новій задачі на питання «які скіли в тебе є?» Claude називає `vault-setup` і три `litnote-*`.

## 6. Налаштувати сховище під вашу тему (15–20 хв)

У задачі з кроку 5 написати:

> налаштуй сховище

Скіл `vault-setup` розпитає про тему, заклад, дедлайни й задум, а потім:

- заповнить `00_admin/config.md`;
- складе **чернетку** протоколу огляду — питання дослідження (RQ), критерії відбору, пошукові запити — і попросить їх погодити;
- заповнить `PROJECT_PROMPT.md` і титул;
- перевірить Python, git, автоекспорт Zotero;
- зробить перший коміт.

Після цього:

1. Прочитати RQ у `00_admin/protocol.md` і виправити, що не так. **Це ваші дослідницькі питання** — від них залежить усе, що збиратиметься далі.
2. Скопіювати текст з `PROJECT_PROMPT.md` (нижче лінії) в **інструкції проєкту** з кроку 5.3.
3. `git push` у терміналі (якщо репозиторій з GitHub).

✓ готово, якщо `config.md` заповнений, а в `protocol.md` стоять ваші RQ.

## Робочий цикл

Кожен рядок — **окрема нова задача** в проєкті (так дешевше: кожен етап читає лише своє).

| Що | Сказати Claude | Що робите ви |
|---|---|---|
| Stage 1 — зібрати джерела | «збери джерела по RQ1» | вставити в Zotero ідентифікатори зі списку Claude (по одному: чарівна паличка → DOI → Enter) |
| Stage 2 — прочитати | «опрацюй чергу нотаток» (5–10 статей за раз) | — |
| Stage 3 — перевірити | — | у `_matrix.md` → «Черга на верифікацію»: звірити числа з PDF, поставити `verified_by_human: true` |
| Stage 4 — прибрати | «обслуговування бази» | запустити `build_cites.py`, якщо Claude попросить |
| Зберегти | «закоміть» | `git push` |
| Писати розділ | «пиши підрозділ 1.2 за нотатками» | редагувати |

Стан бази будь-коли: `python 90_pipeline/collect/state.py .`

## Якщо щось не так

| Симптом | Причина → що робити |
|---|---|
| У сховищі з'явилась тека `_to_delete/` | Claude не може видаляти файли в підключеній папці, тож складає туди git-локи. Безпечно видалити руками будь-коли. |
| `git` пише `Unable to create '.../index.lock': File exists` | Застряглий лок після хмарної сесії: видалити вказаний `.lock`-файл і повторити. |
| `library.bib` не оновлюється | Zotero не запущений або експорт створено без **Keep updated** — повторити крок 3.4. |
| Таблиці в `_matrix.md` порожні, хоча нотатки є | Нотатка з непарсабельним YAML випадає з Dataview: `python 90_pipeline/collect/lint_notes.py 10_literature/notes 10_literature/hubs` покаже яку. |
| Claude каже, що не бачить PDF | Не підключено теку Zotero `storage` до задачі (крок 5.4) або в `config.md` інший `zotero_storage`. |
| Claude робить десятки однакових веб-запитів | Нагадати: «віяло запитів — скриптом», див. `CLAUDE.md`, «Обмеження інструментів». |

## Оновлення шаблону

Коли автор шаблону покращить скіли:

1. Завантажити новий `skills/dist/research-vault.plugin` (або `.zip`) і встановити поверх.
2. Скрипти й `CLAUDE.md` — скопіювати вручну з репозиторію шаблону; `00_admin/config.md` і все у ваших нотатках шаблон не чіпає.
