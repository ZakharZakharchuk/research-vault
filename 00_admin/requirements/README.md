# Вимоги й методичні правила до роботи

Офіційні правила кафедри та курсу: структура, обсяги, формулювання, оформлення. Джерело істини, коли пишемо `70_writing/`; суперечність між цими файлами й нашими звичками вирішується на користь цих файлів.

Як додавати вимогу:

1. Знімок сторінки (Moodle, методичка PDF) — у Zotero, щоб був оригінал.
2. Текстова копія — сюди, окремим `.md` на кожну тему (напр. `literature-review-chapter.md`).
3. Рядок у таблиці нижче.

Стандарти з обмеженням на відтворення (ДСТУ) — лише локально: `dstu-*.txt` і `*.pdf` уже в `.gitignore`.
