# Для автора шаблону

## Опублікувати (один раз, ~10 хв)

1. GitHub → **New repository** → `research-vault`, Public або Private (тоді додати друзів у Collaborators).
2. У цій папці:
   ```
   git remote add origin https://github.com/<ви>/research-vault.git
   git push -u origin main
   ```
3. Репозиторій → **Settings → General → Template repository** ✓.
4. Надіслати друзям посилання й сказати: «відкрий SETUP.md».

## Перенести покращення зі свого сховища

Робоче сховище й шаблон — **різні** репозиторії. Шаблон не містить нічиїх даних, тож переносити лише загальне:

| Змінилось у вашому сховищі | Що робити в шаблоні |
|---|---|
| SKILL.md | скопіювати в `skills/<назва>/`, прибрати шляхи/тему (замість них — посилання на `00_admin/config.md`), `python skills/build.py`, закомітити разом із `skills/dist/` |
| скрипт у `90_pipeline/collect/` | скопіювати; перевірити, що в коді немає шляхів і citekey вашої бібліотеки |
| розділ «Обмеження інструментів» у `CLAUDE.md` | дописати пункт сюди ж, з датою перевірки |

Перевірка перед комітом — нічого особистого не просочилось:

```
git grep -n -i -E "<ваше прізвище>|<ваш нік>|<частина вашого шляху>|<ключове слово вашої теми>"
```

Порожній вивід — можна пушити.

## Версії

`skills/build.py` → `VERSION`. Підвищувати при зміні скілів: `1.0.x` — правки тексту, `1.x.0` — нова поведінка. Друзі бачать версію в картці плагіна.
