# Дані

Уміст цієї теки **не потрапляє в git** (див. `.gitignore`) — великі файли й часто ліцензійні обмеження.

Тримайте тут по підтеці на кожен набір даних і короткий `README.md` у кожній: звідки взято (посилання, версія, дата), ліцензія, як отримати заново. Ці README теж ігноруються; якщо хочете їх у git — додайте виняток у `.gitignore`.
