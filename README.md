# research-vault

Шаблон дослідницького сховища з Claude як асистентом огляду літератури. Підходить для будь-якої роботи, що спирається на джерела: диплом, PhD, стаття, курсова, звіт або власне дослідження. Тип роботи — одне поле в `00_admin/config.md`.

**Zotero** (факти) → **Obsidian** (мислення) → **Git** (версії), а Claude веде конвеєр: знаходить статті, читає PDF, пише літературні нотатки з якорями на сторінки, підтримує базу в порядку. Ви — перевіряєте й пишете.

## Що всередині

| | |
|---|---|
| Структура папок | `00_admin` … `90_pipeline`: адмінка, література, дані, експерименти, система, стаття, текст (`70_writing`), зустрічі, скрипти |
| `CLAUDE.md` | правила для Claude: конвеєр, обмеження інструментів, стиль, git |
| `00_admin/config.md` | **єдине місце з вашими даними**: тема, шляхи, дедлайни |
| `00_admin/protocol.md` | шаблон протоколу огляду: RQ, критерії відбору, запити |
| `10_literature/_matrix.md` | панель черг на Dataview: що читати, що звірити, ядро огляду |
| `skills/` | 5 скілів Claude + готові файли для встановлення в `skills/dist/` |
| `90_pipeline/collect/` | скрипти обліку: стан бази, лінтер нотаток, заготовки, цитатний граф |
| `90_pipeline/build_docx/` | збирання розділу в .docx за ДСТУ (бета) |
| `.obsidian/` | налаштоване сховище з плагінами Dataview і Zotero Integration |

## Скіли

| Скіл | Що робить | Як викликати |
|---|---|---|
| `vault-setup` | перше налаштування: розпитує й заповнює config, протокол, інструкції проєкту | «налаштуй сховище» |
| `litnote-collect` | Stage 1: пошук через Consensus і arXiv → Zotero | «збери джерела по RQ1» |
| `litnote-summarize` | Stage 2: PDF → літературна нотатка з якорями на сторінки | «опрацюй чергу нотаток» |
| `litnote-maintain` | Stage 4: синхронізація шапок, `cites`, хаби, `relevance` | «обслуговування бази» |
| `vault-git` | коміт англійською, прибирання git-локів у змонтованій папці | «закоміть» |

`litnote` = *literature note*, літературна нотатка: одна стаття → одна нотатка `10_literature/notes/@citekey.md`.

Stage 3 — верифікація — тільки ваша: звірити числа з PDF і поставити `verified_by_human: true`.
